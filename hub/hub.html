QuickJump — always-on-top bar

Chrome can float a Picture-in-Picture window above every other window, on any OS. It stays up as long as this pinned tab stays open.

  • Keep this tab pinned and leave it open — closing it closes the bar.
  • Drag the floating window anywhere; it stays above other apps.
  • Prefer a real window instead? Use the popup-window mode plus the KWin rule (see README).
